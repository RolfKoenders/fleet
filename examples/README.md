# My fleet

This is a fleet config repo: it says how every machine I run coding agents on should be set up. The `fleet` tool reads it and makes each machine match. The tool itself lives in its own repo and is not in here.

Every file is commented. Read them in this order:

1. `fleet.yaml`: which version of the tool the machines run.
2. `catalog/skills.yaml` and `catalog/mcp.yaml`: everything that can be installed, defined once.
3. `hosts/_defaults.yaml`: what every machine gets.
4. `hosts/laptop.yaml` and `hosts/server.yaml`: what each machine adds or takes away.
5. `config/`: the files that get linked into place, such as the shared instructions.

Keep this repo private. It will hold your encrypted secrets in `secrets/` once you set the first one with `fleet secrets set`. `.sops.yaml` is generated by fleet; do not edit it.

Day to day:

- `fleet diff` shows what an apply would change.
- `fleet push` commits and pushes this repo, then applies it on every machine.
- `fleet update` moves the pinned tool version to the latest one. It changes `fleet.yaml` and nothing else, so you can look at it before you push.
